Add your app base URL(s) here, one URL per line.

Example:

https://your-app.koyeb.app
https://your-app.onrender.com
https://yourdomain.com

Note:
This is an example file and will not be loaded automatically.

Before deployment, either rename this file to another name
(for example, base_urls.txt) or create a new .txt file in
the root directory and add your own app URL(s).

You can create multiple .txt files if needed.
The app will automatically read all .txt files in the root
directory and ping every valid URL starting with http:// or https://.
